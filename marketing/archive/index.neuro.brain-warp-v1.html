01 · The System

One test. Three signals. One hire.

PIPE replaces résumé screening, take-homes, and first-round whiteboard interviews with one rigorous, proctored challenge. You create the pipeline. We run the test. You read the cited verdict.

◆ 01 · The Test

The same rigorous test for every candidate.

Multi-turn code review and implementation, tuned to the role. Planted bugs. Architectural trade-offs. Real pushback from an AI interviewer calibrated to the senior engineers who'd actually work with the hire. Uniform. Defensible. Survives AI assistance.

◆ 02 · The Friction

The AI pushes back.

The code defends itself — sometimes correctly, sometimes with false authority. The candidate must hold ground with evidence or update when the pushback is valid. You hear how they think when challenged. Cluely can't help.

◆ 03 · The Artifact

One cited verdict. Rigorous.

A cross-family model panel scores the conversation on three calibrated axes — Communication, Technical, Judgment — with quoted moments as evidence. Every decision traceable. Months later, still defensible.

02 · The Pipeline

One pipeline. Six stations. Calibrated end-to-end.

Vetting is the smallest part of a real hire. PIPE runs the whole funnel — calibration, sourcing, outreach, assessment on real repos, panel scoring, defensible decision. Every station emits a typed artifact that auths into the next. Hover a station.

Ⅰ.

Calibrate

Read the role before you read the résumé.

→ The role, understood

Every hire starts with a calibration interview. Your hiring manager, your tech lead, and whoever else will say yes or no — each answers the same six questions, separately. Disagreements surface as first-class fields, not as a 3 a.m. Slack thread two weeks into the search. You also set a culture benchmark — five sliders that capture how your team actually works. That benchmark, plus the role overlay, tailors every downstream stage: the challenge content, the pushback intensity, the culture interview, the scoring rubric. No generic "culture fit" boilerplate.

Assess

Real dev environment. Real pull requests. Live when you want it.

→ The work, captured verbatim

A real pull request on a real open-source project, matched to your stack, in a production-grade browser IDE — real editor, real terminal, real git. The code pushes back: cites false authority, holds ground under friction. The candidate has to prove the point, not pattern-match. Async by default; flip it live for coding or pair-programming on the same rubric. A separate structured behavioral track, STAR-format, tailored to the five sliders you set at calibration.

Score

Six graders. One verdict. Every number cited.

→ A scorecard you can defend

Specialists grade both tracks in parallel — six for the code review, eleven for the culture interview (one per competency, one per culture axis, plus a synthesis pass that writes a three-paragraph narrative). Each score is anchored to a verbatim moment: no evidence, no score. A silent calibration layer measures every grader against a stricter reference and escalates anything that drifts. Scores that can't cite a moment get coerced to null and flagged for your review — never fabricated.
