# Superseded Strategy v2 Source Documents

**Archived:** 2026-06-19
**Reason:** Superseded for living-context and matching architecture by
`knowledge/plan/living-context-repo-matching-plan.md` and ADR-043.

This archive contains the original Strategy v2 source series. The documents are
historical planning inputs only. They are no longer active because several parts
conflict with the current goal by prescribing:

- Neo4j-first semantic graph ownership rather than D1-authoritative rebuildable
  projections.
- Fixed semantic node/sub-element types such as `Skill`, `Experience`, and
  `CulturalSignal` as graph truth.
- Hand-curated skill adjacency tables and ESCO-preferred vocabulary.

The corrected, active direction is captured in:

- `knowledge/plan/living-context-repo-matching-plan.md`
- `knowledge/research/outputs/living-context-hyperedge-intake.md`
- `knowledge/docs/decisions/current/ADR-043-no-hard-coded-semantic-taxonomy.md`
