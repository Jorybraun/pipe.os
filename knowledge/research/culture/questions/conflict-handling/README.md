# Conflict handling questions

Questions that score the **conflict handling** competency (see `../../dimensions/conflict-handling.md`).

A good conflict-handling question elicits a specific past disagreement with a named type of person (peer, manager, stakeholder) and requires the candidate to describe the other side's position and the resolution process. Avoid questions that can be answered with "we found common ground."

See `../README.md` for the template. Populated in task #5.
